# 闲闲社区 - 本地二手闲置交易微信小程序

## 项目简介

闲闲社区是一款面向本地社区的二手闲置物品交易微信小程序，旨在为邻里之间提供便捷、安全的闲置物品交易平台。

## 主要功能

### 1. 用户系统
- 微信一键登录
- 实名认证（可选）
- 手机号绑定（可选）
- 信用体系

### 2. 物品发布与展示
- 图文上传，支持多图上传
- 物品信息填写（标题、描述、新旧程度、原价、现价、分类）
- 自动获取用户位置信息
- 首页按发布时间倒序展示
- 下拉刷新
- 分类筛选
- 关键词搜索
- 按距离排序

### 3. 交易沟通
- 小程序自带客服消息功能
- 支持文字和图片内容

### 4. 收藏与信用
- 物品收藏功能
- 基于交易完成率、评价的信用体系
- 高信用用户标识
- 评价功能（仅对完成交易双方开放）
- 显示用户卖出闲置记录

### 5. 圈子功能
- 热门小区榜（基于用户定位）
- 邻里圈动态流
- 支持发布求购、以物换物、免费赠送等信息

### 6. 安全机制
- 系统自动检测联系方式、站外交易等敏感词
- 用户举报功能
- 管理后台人工审核

### 7. 其他功能
- 地址管理
- 交易须知提醒

## 技术栈

- 微信小程序原生开发
- 原生 JavaScript
- WXML + WXSS

## 开发说明

1. 在微信开发者工具中导入项目
2. 配置小程序 AppID
3. 修改 `app.js` 中的 API 地址为实际后端地址
4. 根据实际需求调整页面逻辑和样式

## 注意事项

1. 定位功能需要在微信公众平台配置相关权限
2. 客服消息功能需要在微信公众平台配置企业微信
3. 敏感词过滤规则可根据实际需求调整
4. 信用体系计算逻辑可根据业务需求优化
